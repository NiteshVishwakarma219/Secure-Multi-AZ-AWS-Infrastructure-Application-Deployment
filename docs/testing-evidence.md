# Testing Evidence Log

Use this file to record the outcome of each test in `runbooks.md`. Paste
CLI output, screenshots (as image links), or console excerpts as you go —
this file *is* the evidence artifact for your project report and viva.

```
### <Test name> — <date>

**What I did:**


**What I expected:**


**What actually happened:**


**Evidence (CLI output / screenshot):**


**Time to detect / time to recover (if applicable):**


**Follow-up / what I'd change:**

```
